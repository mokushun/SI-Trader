## 詰めの結果

- **エントリーは「遅れる」方向だけが致命的で、「早い」方向は無害。**
  遅延（決済10:30固定）: 09:56 で +0.97（半減）、09:57 +0.70、09:59 +0.05、
  10:00 −0.20、10:05 −0.79。下落はフィキシング直後の数分に集中する。
  一方プリエントリー: 09:52 +1.67、09:53 +1.89、**09:54 +1.93（t=4.37）** と
  09:52-09:55 がプラトーをなし、09:54→09:55 の mid 変化は −0.05pip（ほぼゼロ）。
  つまり天井は 09:53-54 の時点で実質到達しており、09:55 のプリントを奪い合う必要はない。
  実務含意は大きい: 発注窓を **09:54** に置けば、秒単位の約定競争を避けても
  バックテスト成績は落ちない。逆に 09:55 を過ぎてから追う設計は不可。
  留保: M1 では分内の decay は観測できない。09:56 バー始値まで遅れたケースが
  「60秒遅れの最悪値」であり、数秒遅れのコストは 0〜0.8pip の間のどこか（未観測）
- **決済はプラトーで、10:30 はスパイクではない。** 10:15 +1.66 / 10:20 +2.05 /
  10:25 +1.96 / 10:30 +1.79 / 10:35 +1.39 と 10:15-10:30 域は安定。
  10:20 が数値上ピークだが、ここで 10:20 に乗り換えるのは同一データでの
  マイニングなので採らない。事前固定の 10:30 を維持する
- **曜日は水・金が担い、火曜はゼロ。** 水 +3.11（t=4.39、n=215）、金 +2.34（t=3.17）、
  **火 −0.04（t=−0.06、n=219）**。火曜を事後的に落とすのはマイニングなので原定義は
  変えないが、前方記録で最初に疑うセルは火曜。
  木曜（原定義では仲値ロングの 05:35 決済に合わせて除外されていただけ）は
  +1.61（t=2.00）で半期も両方プラス（+1.48/+1.71）。フィキシング自体は木曜にも
  あるので構造的には候補だが、今回のデータを見て足すのも事後判断になる。
  **木曜と月曜（+0.76、n.s.、半期で符号反転）は前方記録のペーパー系列**として
  同時刻に記録だけし、実弾の原定義（火水金）には入れないのが筋
- **ペアは USD_JPY のみを再確認**（2015-2026、五十日・火水金）: EUR +0.61（n.s.）、
  GBP +0.34（n.s.）、AUD −0.69、CHF −0.12。クロスは 2015-20.9 が全てマイナスで
  2020.10 以降だけプラス（=レジーム依存）なのに対し、USD は両期プラス
  （+0.78 / +2.76）。時代不変なのは USD だけ、という 2026-11-03 の読みは維持
- **スリッページ耐性**: 実行可能価格に既に往復スプレッド込みの上で、追加コスト
  +0.5pip でも +1.29（t=3.08）、+1.0pip で +0.79（t=1.89）。損益分岐の追加コストは
  定義上 +1.79pip。09:55 バーのスプレッドは五十日でも中央値 1.70pip で
  非五十日と同一（フィキシング分にスプレッド拡大の罰則はこのフィードでは無い）。
  本当の未知数はスプレッドではなく上記の「分内の約定位置」
- **リスクの形**: 651件で合計 +1,166.9pip、年約30件（月2.5件）。累積の最大DD
  −141.5pip、最悪トレード −47.5pip、最大連敗8。負け年は 22年中5年
  （2008, 2012, 2014, 2015, 2018）で、深いのは 2015（平均 −3.69、PF 0.323）と
  2018（−2.96、PF 0.476）。2026年はここまで +0.12（n=25）と軟調。
  100単位なら（JPYペアは 1pip = ¥1）期待値 ≈ +¥1.8/件、累積最大DD ≈ −¥142 の
  桁 — 収入ではなく「約定データを買う試験」の規模感
  （2026-11-05 訂正: 初版の円換算は単位を取り違えていた。pip建ての数値は不変）
- **仕組みの確認（記述のみ）**: 朝の値動きで割ると単調でない。朝が下がった日
  （00:00→09:55 mid ≤0、n=249）でも +2.07（t=2.79）と最大級で、非五十日は
  朝の動きの全バケットでマイナス。つまり単なる「朝上がった分の反動」ではなく、
  五十日に固有の「09:55 で実需の買いが消える」効果として読む方が合う。
  朝の動きによるフィルタは正当化できない（定義は単純なままが良い）

## 事前登録案（この検証をもって定義を固定するなら）

- 原定義（実弾候補）: USD_JPY、JST 日付が day%5==0、曜日は火・水・金。
  **09:54 に売り発注**（窓は 09:54 台、プリント前）、**10:30 に買い戻し**。
  理論ベンチマークは従来どおり 09:55 bid始値 → 10:30 ask始値（2005-2026 の
  記録と接続するため）。毎回、実約定価格とベンチマークの差（pip）を記録する
  — M1 では測れない分内約定位置こそが前方記録の主目的
- ペーパー系列（実弾なし、同ースクリプトで同時記録）: 木曜・月曜の五十日、同条件
- 判定の目安（例）: 実弾＋ペーパー合わせてではなく原定義のみで、最初の30件
  （約12か月）時点で (a) 実約定ベース平均 > 0、(b) ベンチマーク比の
  約定劣化が平均 1pip 未満、を満たせば「再現」、平均 ≤ 0 なら不成立として終了。
  途中での定義変更（火曜除外・決済10:20化など）はしない
- 未決定事項（ユーザーの判断）: 実施するか否か、場所（GMO は仲値ロングの
  09:55 決済と同分に売りが立つ順序問題、OANDA は共有口座だがロング決済後に
  売るので証拠金は先に空く）、サイズ（GMO 試験と揃えた 100 単位が自然）

## 不確かな点

- 分内の価格パスは M1 では原理的に測れない。前方記録でしか埋まらない
- 候補自体は 2015-26 の最良セル探索から出たもの。多重比較の疑いは、
  2005-14 という独立期間で効果量まで一致したことでかなり薄まったが、ゼロではない
- 火曜ゼロと 2026年の軟調（+0.12）は、効果が曜日・時期で均一でない可能性を示す
- 本検証は OANDA フィード前提。GMO で実施する場合の 09:54-55 の約定位置は別物になる
