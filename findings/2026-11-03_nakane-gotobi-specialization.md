# 仲値: 現行のペア・サイズ配分 vs 五十日特化（2026-11-03、Muse）

スクリプト: `scripts/nakane_gotobi_specialization.py`
出力: `outputs/nakane_gotobi_specialization_out.txt`
データ: m1.db 2015-2026、5円ペア、実行可能価格。**等量（1単位/ペア）の近似**
（実売買は曜日・ペア別 VOLS と +3000 ゴトーボーナス ×1.4 だが、方式間の順位を見る）

方式: S0 全日フル（現行構造）/ S1 ゴトー日のみ / S1x2 ゴトー日のみ2倍 /
S2 傾斜（ゴトー日1.0・非ゴトー日0.5）/ S3 選択的（ゴトー日は全ペア、
非ゴトー日は USD_JPY・GBP_JPY のみ）

## 結論

- **ペア構成は現行のままでいい。弱いのはペアではなく非ゴトー日の脚。**
  ゴトー日は全ペア・両時代でプラス（PRE +2.17〜+6.02、POST +4.61〜+9.80）。
  AUD/CHF を外すと本物のゴトー日利益（POST で AUD +4.61、CHF +9.77・t=4.42）を切る。
  非ゴトー日は POST でも USD (+2.58, t=2.06) と GBP (+2.46) 以外はほぼゼロ
  （AUD −0.03、EUR +0.98、CHF +0.59）、PRE では EUR 以外マイナス（CHF −2.52, t=−2.52）
- **全日フル（S0）は今の時代では正解だが、時代耐性は最弱。** POST では総計最大
  （+16,876）だが、PRE では唯一の負け方式（−1,366）で、最悪月も最深（FULL で −1,675）
- **ゴトー日のみ（S1）は S0 の 11 年総計とほぼ同額（+15,277）を 19% の取引量で達成**し、
  月次 t は 4.42（S0 は 2.32）、最悪月 −491。ただし POST では等量だと総計の
  約4割を取りこぼし、月8日程度への集中が増える。2倍にした S1x2 は POST 総計でも
  S0 を上回る（+20,430）が、ゴトー日単日の露出が跳ね上がり、証拠金ゲート
  （2026-10-30 に実際にスキップ発生）との兼ね合いが悪化する
- **データ上の甘い所は傾斜／選択的。** S2 は FULL 総計 ≈S0 で t=3.66・最悪月 −798。
  S3 は総計最大（+17,982）、t=4.18、正の月 66%。ただし S3 の「非ゴトー日は
  USD/GBP のみ」はこのデータ自体から設計した面があり、POST でも有意なのは
  USD だけ（GBP は t=1.54）という留保が付く。機械的な S2 が頑健な版
- 含意: 変えるなら「ゴトー日をさらに太く」ではなく「非ゴトー日の弱いペアを
  薄く」が先。ゴトーボーナスを半減したばかりの経緯（ゲート・単日集中）とも
  整合する。変更するかどうかはユーザーの判断で、本検証は現行維持も否定しない
  （POST レジームが続く限り S0 が総計最大）

## 追補: 実売買の実ウェイトでの再計算（同日、ユーザー提供の VOLS）

実ウェイト（曜日別 VOLS は日曜始まり: USD 3100/2800/2500/2200、
GBP 3200/2800/2500/2200、EUR 2700/2400/2200/1900、AUD 2800/2500/2300/2000、
CHF は一律 100、火〜金。×1.4 と +3000 ボーナス込み、円換算）でも順位は同じで、
現行設定（LIVE）は POST・FULL とも総計最大・月次 t も最良級だった
（出力: `outputs/nakane_gotobi_specialization_live_weights_out.txt`）:

- PRE: LIVE +193,353円（t=1.21）に対しボーナスなしは −19,247円。
  **+3000 ボーナスだけで PRE がマイナスからプラスに転じる**
- POST: LIVE +977,814円（月平均 +13,395円、t=4.63、最悪月 −36,003）。
  ゴトー日のみ（実サイズ） +713,884円、ボーナスなし +548,775円
- FULL: LIVE +1,171,167円（t=4.30） vs ゴトー日のみ +1,076,427円（t=4.36）で
  有意性は互角、総計は LIVE が上、最悪月はゴトー日のみが浅い（−36,640 vs −48,862）
- CHF は素の VOLS が 100 のため、実質「ゴトー日だけ意味のあるサイズ」
  （ゴトー日は (100+3000)×1.4=4,340）になっており、選択的方式が
  既に一部組み込まれた形。ユーザーは現行設定（+3000 のまま）を
  もう少し続ける判断をした（2026-11-03）

## 不確かな点

- 等量近似の本編に対し、追補は実ウェイトで再計算した。ただしどちらも
  スワップ・スリッページは含まない（従来の検証と同条件）
- ポートフォリオ統計は日次・月次の合計ベースで、日中の証拠金推移
  （ゲートに触れるか）は再現していない。S1x2 の評価はその分甘い
- 2005-2014 のクロス円データがないため、時代判定は 2015 年以降のみ
