# 仲値 VOLS: POST 加味・1日≈10,000 単位の調整案（2026-11-03、Muse）

スクリプト: `scripts/nakane_vols_post_adjusted.py`
出力: `outputs/nakane_vols_post_adjusted_out.txt`
ユーザー指示: 厳密案が POST を加味していなかった点を直し、1日の注文が
10,000 通貨前後になるよう調整する。

## 方式

- スコア = （FULL の非ゴトー日曜日別平均 + POST の同平均）/ 2。
  POST は FULL の部分集合なので、これは直近時代を実質2倍に重み付けしつつ
  長期の時代保険を捨てない配分
- 曜日ごとに素の合計 10,000 を正のスコアへ比例配分。下限100、1セル上限 5,000
  （超過分はスコア比例で再配分）
- 金曜は正のスコアが CHF のみのため上限が効いて 5,400 に着地。
  無理に 10,000 にする版（CHF 金曜 9,600）も ADJ-Fri10k として併記評価

## 調整案（素の VOLS、火/水/木/金）

|---|---|---|---|---|

## 評価（実ウェイト、+3000・×1.4 込み、円）

- ADJ: PRE +217,718（最悪月 −44,548 は4案中最良）、POST +1,145,837
  （t=5.07 で手提案 PROP2 の 5.08 と同等、総計は上）、FULL +1,363,556
  （t=4.74、最悪月 −44,548 は PROP2 の −49,864 より浅い）
- 露出は曜日均一で約 14,000 単位/日（ゴトー日 35,000）、金曜 7,560/28,560 と
  ゲートに触れた水準（53,760）を大きく下回る
- ADJ-Fri10k（金曜を 10,000 に強制）: 総計は増える（FULL +1,492,896）が
  POST の t が 4.86 に落ち、最悪月も −40,346 に悪化。CHF 金曜単独への
  集中はリスク調整後では割に合わない
- 手提案（PROP2）と調整案（ADJ）は出発点が違うのに形が近い
  （USD/GBP の火〜木厚め、EUR 中位、AUD は水曜のみ、金曜は CHF＋名目）。
  2つの独立した作り方が同じ形に収束するのは、形の頑健さの傍証

## 不確かな点

- スコアのブレンド（FULL と POST の単純平均）は一つの選択。POST のみで
  作れば USD/GBP の火水がさらに厚くなり、EUR 木曜などは消える
- 基礎統計は非ゴトー日の平均のみで、ゴトー日の曜日別差（木曜ゴトー日の
  突出など）はボーナス一律 +3000 の側に残置されている
- 採用はユーザーの判断（本書は調整案の提示と評価まで）
