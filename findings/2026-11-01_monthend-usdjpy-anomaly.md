# 検証サマリー 2026-11-01（月末の USD/JPY アノマリー）

検証者: Muse
根拠:
- `scripts/monthend_usdjpy_anomaly.py`
- `outputs/monthend_usdjpy_anomaly_out.txt`
- 補助計算（年層別のペア差）は findings 作成時に同スクリプトの関数で再計算した値

## 問い

ユーザーの仮説（口伝で曖昧）:
- 「月末の USD/JPY は上がる。20日過ぎくらいから買い始めて、月末に決済する」
  というアノマリーが昔から言われている。
- 曖昧な点: 買い始める日が「20日過ぎくらい」で不特定／月末決済の時刻も不特定／
  「上がる」が通常のドリフト比でどれだけか不明。

## 定義（固定、事後最適化なし）

- タイムゾーン: すべて JST (Asia/Tokyo)。暦日・月境界も JST。銘柄は USD_JPY のみ。
- 本定義（月末区間）: エントリー = 各月21日 00:00 JST 以降に最初に現れる M1 バーの
  ask 始値で買い。決済 = 月末日（暦日）23:59 JST 以前で最後の M1 バーの bid 終値。
  スプレッド込み（買いは ask、売りは bid）。手数料・スワップは含まない
  （約7営業日の保有ではスワップは本来無視できない。USD/JPY ロングのスワップは
  概ねプラス側なので本検証はロング側に保守的。ただし対照区間も同条件）。
- 対象月: 月末区間が完全に取れる **2020-10 〜 2026-09 の 72 か月**。
  2020-10 は DB 開始が 2020-10-01 のため月としては部分月だが 21日→月末区間は
  完全に含まれるため含めた（同月のセグメント1のエントリーだけ DB 初バー
  2020-10-01 09:00 JST になる）。2026-10 は DB が 2026-10-29 で終わり
  月末（10/31）決済ができないため除外した。
- エントリーの滑り: 21日が日曜の 11 か月は翌月曜の初バーで入っている。
  21日が土曜の 10 か月は土曜 00:00 JST のバー（金曜 NY セッションの継続）で入っている。
  いずれも「21日 00:00 以降の初バー」という同一ルールの帰結。
- 主対照（交絡対策）: 各月を セグメント1（1日→10日）/ セグメント2（11日→20日）/
  セグメント3（21日→月末、本定義）の3区間に分け、全区間を同じ実行可能定義で計算し、
  対応のあるペア比較をする。これにより 2021〜2024年の円安ドリフト
  （どの区間も上がりやすい）という交絡を抑える。
- 副対照: 全期間の「任意の開始日から、月末区間と同じ暦日数 D（8〜11日）ぶん保有する
  ロング」の分布（D ごとに n≈1,890、重なりあり）と、月末区間の位置
  （パーセンタイル＋モンテカルロ、シード42、20,000回）。
- 感度（事前宣言分のみ）: エントリー日 20日 / 21日 / 25日 の3通り。

## 結論

**月末区間だけが上がるというアノマリーは言えない。月末区間のプラスは、
期間全体の円安ドリフトの言い換えである。**

- 本定義（21日→月末）: 72か月で平均 **+0.1592%**、中央値 +0.3719%、勝率 61.1%、t=+1.01。
  単体では弱いプラスに見えるが、下記のとおり特別さはどこにも無い。
- 同じ月の他区間も全部プラス（セグメント1 +0.0839% / セグメント2 **+0.2923%** /
  セグメント3 +0.1592%）で、月末区間は真ん中。むしろ中旬（11日→20日）が一番大きい。
- ペア差はゼロ: seg3 − seg1 = +0.0753%（t=+0.33）、seg3 − seg2 = −0.1331%（t=−0.61）、
  seg3 − 他区間平均 = **−0.0289%（t=−0.15）**。月末区間が3区間中最大だった月は
  27/72 = 37.5%（偶然なら約33%）。
- 副対照でも月末リターンのパーセンタイル平均は **50.0**（中央値 52.6）。
  ランダムな開始日の組合せの平均が月末区間平均以上になる確率は p=0.5807。
  つまり「いつ買っても同じくらい上がった」期間だった、が正確な記述。

## 根拠

### 1. 3セグメントともプラス = ドリフトの反映

全期間（2020-10〜2026-09）は USD/JPY が約105円から約157円へ上がった期間であり、
ロングの区間リターンは月内のどこで切ってもプラスに偏る。月末区間の勝率 61.1% も
セグメント1 の 58.3%、セグメント2 の 59.7% とほぼ同じで、月末固有の勝ちやすさはない。

### 2. 円安期に絞ってもペア差はゼロ

2021〜2024年（円安期、n=48）: 月末区間平均 +0.2909% だが、ペア差
seg3 − 他区間平均 = **+0.0038%（t=+0.02）**。円安期の月末のプラスは
その月の他の区間と完全に同じ大きさであり、月末フロー固有の上乗せは検出できない。
2025〜2026年（下落局面含む、n=21）: 月末区間平均 −0.0708%（t=−0.31）、
ペア差 −0.1038%（t=−0.34）。ドリフトが消えると月末のプラスも消える。

### 3. 年別層別

月末区間平均: 2020年（3か月）−0.3389% / 2021年 +0.5885%（勝率75.0%、t=+2.22）/
2022年 +0.1636%（66.7%）/ 2023年 +0.7982%（75.0%、t=+2.52）/ 2024年 −0.3869%（50.0%）/
2025年 +0.1508%（50.0%）/ 2026年（9か月）−0.3662%（55.6%）。
2021年と2023年にプラスが目立つが、これは円安が強かった年と重なるだけで、
第2節のとおり同年内の他区間も同程度に上がっている（ペア差ゼロ）。
年を7つ見ているので個別年の t≈2.2〜2.5 は多重検定として割り引く必要もある。
2024年は7月末の急落（月末区間 −4.4762% が全期間の最小）もありマイナス。

### 4. 感度は平坦

エントリー日を変えても 20日 +0.1147%（t=+0.71）/ 21日 +0.1592%（t=+1.01）/
25日 +0.0738%（t=+0.59）と同水準で、特定の開始日に山は無い。
「20日過ぎ」は開始日をどう切っても同じ結論になる（裏を返せば、
開始日を事後に選んで良く見せる余地もこの範囲には無い）。

### 5. 既存の月末候補（London fix）との関係

2026-10-30 の London fix 検証で残った「月末日のフィックス直後30分の USD 高
（合成 +2.74bp、t=2.70、n=72）」とは時間スケールが違う別件であり、
本結果と整合も矛盾もしない。30分窓の数 bp 級の効果が実在しても、
10日間保有の区間リターン（sd 1.34%）の中では誤差に埋もれる。
逆に本検証が否定したのは「20日過ぎから買って月末に売る」という
複数日ドリフト型の主張であり、月末日の30分窓の候補は別途残る。

## 限界・不確かな点

- **対照プールの t 値は使えない**: 副対照の全開始日トレードは窓が重なるため
  独立サンプルではなく、プール自体の t（+4.5〜+5.8）は有意性の根拠にならない。
  本検証では分布としての位置（パーセンタイル）とモンテカルロだけを使った。
- **スワップなし**: USD/JPY ロングのスワップは概ねプラスなので、含めれば
  全区間が等しく底上げされる方向。月末区間だけを特別にする材料にはならない。
- **「月末」の代替定義は測っていない**: 月末最終「営業日」基準、NY 時間基準の
  月切り、月末日だけの1日保有などは本定義の範囲外。仮説が口伝で曖昧なため
  本検証は暦日・JST で1つに固定した。定義を増やす場合は事前宣言してから測る。
- **実効サンプル**: 月1回しか増えない主張であり、72か月でも t=1 程度の
  小さい効果（平均 +0.16%）が実在するかどうかまでは検出力が届かない。
  言えるのは「他区間・ランダム開始より大きい月末効果は無い」ことまで。
- 2020-10 のセグメント1は DB 初バー（10/1 09:00 JST）始まりで、月初の
  数時間分が欠落している。同月のペア比較への影響は最大でも1か月分。
