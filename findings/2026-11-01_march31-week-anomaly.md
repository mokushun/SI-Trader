# 検証サマリー 2026-11-01（3月31日を含む週のアノマリー）

検証者: Muse
根拠:
- `scripts/march31_week_anomaly.py`
- `outputs/march31_week_anomaly_out.txt`

## 問い

ユーザーの仮説:
- 毎年「3月31日を含む週」（3月31日当日に買うのではない）の月曜日に買い、同じ週の金曜日に
  強制決済すると「かなりプラス」「大きくプラス」になるアノマリーがある。
- 理屈: 3月期決算の機関投資家が全ポジションを解消した後、4月に入る前に大きく動く。
- 銘柄はユーザー未指定のため全21銘柄で測り、USD_JPY を重点とする。
- フィルタ: (a) エントリー時点で RSI が既に高い時は入らない、
  (b) 保有中に1時間足 RSI が70以上になったら利確する（売却フィルタはこれのみ）。

## 定義（固定、事後最適化なし）

- タイムゾーン: すべて JST (Asia/Tokyo)。週の切り方も JST。
- 対象週: 3月31日を含む月〜日週の月曜がエントリー日。対象年 2021〜2026 の6回。
  2020年は m1.db が2020-10-01開始で対象週が無いため対象外。
  年別の月曜: 2021-03-29 / 2022-03-28 / 2023-03-27 / 2024-03-25（3/31が日曜の年）/
  2025-03-31（3/31が月曜で、エントリー日が偶然3月31日自体になる年）/ 2026-03-30。
- エントリー: 月曜0:00 JST のバーは存在しない（下記で再確認）ため「0:00指定は実行不能」とし、
  月曜（JST暦日）最初のM1バーの ask始値で買い。
- 決済（ベースライン）: 取引週としての金曜の最終バー。FX金曜セッションは
  NY金曜17:00 = JST土曜06:00(EDT)/07:00(EST) に終わるため、探索窓は金曜00:00 JST〜土曜08:00 JST
  とし、その最後のM1バーの bid終値で決済。実際の決済時刻は土曜05:57〜05:59 JST だった。
  (参考: JST暦日金曜23:59で切った USD_JPY リターンも出力に併記したが、本判定には使っていない。
  例 2023年: 取引金曜定義 +1.6443% vs 暦日金曜 +1.8701% と、定義で数字は動き得る。)
- リターン: %で統一。(決済bid / エントリーask − 1)×100。スプレッド込み。
  手数料・スワップは含まない（5日保有ではスワップは本来無視できないが m1.db に情報が無い。本検証は価格+スプレッドのみ）。
- RSI: 1H足は JST 1時間集計、終値は各時の最後のM1バーの mid終値。RSI(14) は Wilder ではなく
  単純平均版 (Cutler) で統一（実装をスクリプト冒頭に明記）。
  (a) エントリー直前の完成した1Hバーの RSI >= 70 なら見送り。
  (b) 保有中に完成した1Hバーの RSI >= 70 になったら、次のM1バーの bid始値で利確。
- 対照群: 同銘柄・同年（月曜の暦年）の対象週以外の全週を同じ定義で計算（1銘柄あたり n=293〜294）。
  対象6件の平均以上になる「ランダム6週の平均」の確率をモンテカルロ（シード42、20,000回、非復元抽出）で算出。

## 結論

**この定義では「かなりプラスになるアノマリー」は存在しない。ベースラインは反証された。**

- USD_JPY（重点銘柄）: 対象6週は合計 +0.3218%・平均 +0.0536%・3勝3敗で、
  「大きくプラス」どころか対照群（通常の週、平均 +0.1038%・勝率 59.5%）より悪い。
  ランダムな6週の平均が対象6週の平均以上になる確率は 55.75% (MC p=0.5575) で、完全に通常の週並み。
- 全21銘柄プール: 対象126件は合計 −31.3594%・平均 −0.2489%・勝率 49.2% で、
  対照群プール（n=6,168、平均 +0.0045%）より悪い。
- RSIフィルタ版でも結論は変わらない: プール合計は −13.3536% とベースラインよりは改善するが
  なおマイナス。USD_JPY では見送り0換算の平均 +0.0807% で、対照群平均をなお下回る。
- 個別銘柄で最も良かった EUR_AUD でも MC p=0.0098 は、21銘柄探索の多重検定補正
  （Bonferroni なら有意水準 0.05/21 ≒ 0.0024）を通過しない。アノマリーの「証明」にはならない。

根拠の強さ: 「対象週が特別に良い」という主張に対しては強い反証（対照群と同等以下が
全銘柄プール・重点銘柄・年別クロスの3方向で一致）。一方 n=6/年しかないため、
「小さな効果が絶対に無い」ことまでは証明できない（検出力の限界は下記）。

## 根拠

### 1. 月曜0:00 JSTバーは存在しない（再確認）

- 2021〜2026 の全月曜 × 全21銘柄 = 6,294 組合せで、月曜0:00 JSTちょうどのバーは 0件。
- 月曜初バーの最頻時刻は全銘柄・USD_JPY とも 06:04 JST（USD_JPY では 300週中101回）、範囲は 06:00〜09:11 JST。
- よって「月曜0:00に買う」は文字通りには実行不能で、本検証は初バー代替で測っている。
  元の発見者が使っていたチャート/口座の時刻表示が JST でなかった可能性は残る（後述の限界）。

### 5. RSIフィルタの影響

- エントリー見送り: 126件中18件（USD_JPY は 2021年 RSI 70.14 と 2026年 71.31 の2件）。
  USD_JPY 2021年は見送らなければ +0.7688% だった年を threshold 70.14 という際どい値で捨てている
  （RSIの計算方式が Wilder なら判定が変わり得る水準。方式依存性の実例）。
- 利確発動: 見送りを除く108件中106件 (98%) で発動した。つまりこの「フィルタ」は
  たまに効く安全弁ではなく、ほぼ全トレードの決済を週の前半の最初の上昇1時間に変えてしまう
  別戦略化している。頻発する理由は、1週間の1Hバーは約120本あり、そのどこかで
  14本平均RSIが70を超える事象は珍しくないため。
- USD_JPY の利確内訳: 2023年の勝ち +1.6443% → +0.1592%（月曜09:00に切る）、
  2025年の負け −1.9423% → +0.0073%（火曜02:00に切る）、2024年 −0.0852% → +0.1942%。
  大勝ちを切り、大負けも切るので、符号はその週の値幅の出方次第。実行4件の平均 +0.1211%、
  見送り0換算の平均 +0.0807% はベースライン +0.0536% との差が n=6 では誤差の範囲。
- プール全体では合計が −31.3594% → −13.3536% に改善するが、主因は2025年の大負け週を
  早期に降りたこと（例 SPX500_USD 2025: −8.6685% → +1.2814%、NAS100_USD 2025: −9.3063% → +0.3771%）で、
  同時に2025年の勝ちも消している（EUR_AUD 2025: +5.2202% → −0.1143%）。
  1つの極端な年への依存が大きく、フィルタの優位とは言えない。

## 限界・不確かな点

- **n=6**（年1回×6年）。銘柄を21に広げても同週マクロで同時に動くため独立サンプルは増えない
  （126件を独立とみなす集計はしないこと）。この n では平均 ±0.5% 程度の小さな効果は検出できない。
  言えるのは「大きく/かなりプラスという水準の効果は無い」ことまで。
- **多重検定**: 銘柄未指定で21銘柄を探索したため、最小の MC p=0.0098 (EUR_AUD) でも
  Bonferroni 基準 (0.0024) を満たさない。個別銘柄の良し悪しを拾い読みしないこと。
- **月曜0:00の代替**: 元の発見環境の時刻基準が不明（MT4/MT5 のサーバー時刻等なら
  「月曜0時」の実体は JST 月曜早朝と数時間ずれる）。本検証は JST 初バーで固定しており、
  別時刻アンカーでは数字が変わり得る。ただし対照群との比較（同じアンカーの通常週より良いか）は
  アンカーを変えても大きくは変わらないはず、というのが本結果の読み方。
- **スワップ・手数料なし**: 月〜金の5日保有ではスワップ (特に3倍デー) が無視できない銘柄もある。
  ただし USD_JPY ロングのスワップは概ねプラス側であり、入れても「対照群以下」という順位問題は解消しない。
- **RSI方式依存**: 本検証は単純平均 (Cutler) で統一した。Wilder 方式では見送り/利確の
  タイミングが変わる件がある (USD_JPY 2021 の 70.14 は際どい)。方式を変えて良い結果だけを
  拾うのは事後最適化になるため、本メモでは方式変更の再計算はしない。
- **理屈の検証範囲**: 「機関投資家が全ポジ解消後に大きく動く」フロー自体は価格データだけでは
  直接測れない。本検証が反証したのは、その帰結である「月曜買い→金曜決済が大きくプラス」という
  価格的主張のみ。

## 追記（2026-11-01）元のバックテスト画面の解析

ユーザーが元の発見の MT5 テスタ画面（USD/JPY 1H、2003〜2021年、全19取引）を共有したため、
その取引明細を精査した。こちらはスクリプト検証ではなく画面の読み取り＋検算であり、そのように扱うこと。

- 全19取引が全勝（損益は全てプラス）、初期 10,000 → 最終 21,151.06。18年で約2.1倍（年率換算 約4.2%）。
- 全取引の決済は金曜 22:00（サーバー時刻）。ただし同週金曜で決済されていない取引が5件ある:
  2004年（4/2 → 4/9）/ 2007年（3/30 → 4/6）/ 2013年（3/29 → 4/5）/ 2015年（4/3 → 4/10）は各1週遅れ、
  **2016年は 3/28 買い 113.172 → 12/2 決済 113.691 と約8か月保有**していた。
  よってこの EA の決済は「同週金曜の強制決済」ではなく「金曜22:00に条件を満たした時だけ決済し、
  満たさなければ翌週以降へ持ち越す」ものである（条件が RSI か利益確定かは画面からは確定できない）。
  損失を確定せず含み損を抱えて回復を待つ構造のため、全勝は作られている。
- 検算の傍証: 0.50ロットの理論損益（価格差×50,000÷決済価格）と表示損益の差は、
  通常の1週間保有では一律 −3.07、1週持ち越した4件では −6.66、2016年の長期保有では −128.61 で、
  保有期間に応じたスワップ控除と整合する。長期保有が実在した裏付け。
- グラフの横軸は時間ではなく取引番号（0〜19）で、上の曲線は決済済み残高ベース。
  2016年の保有中に USD/JPY は 99〜100円台まで下げており、0.50ロットでは含み損は概ね
  $6,000〜7,000（当時残高 約$19,230 の 1/3 程度）に達し得たが、曲線には一切現れない。
- 決済が全て金曜22:00に揃うため、「1時間足RSIが70以上になったら（その時点で）売却」という
  常時監視型の説明とも一致しない。RSIが関わるなら判定は金曜22:00時点でのみ行われているはず。
- 期間が2021年で終わっているのは、テスト実行が2022年頃だったためと読むのが自然。
  本検証（強制決済版、2021〜2026、USD/JPY 3勝3敗）とは決済ルールが別物であり、単純比較はできない。

## 追記（2026-11-01）NY時間アンカー感度確認 — 結論は変わらない

JST版の「次にやるなら」にあった NY 時間アンカーを、定義を事前に1本だけ固定して実行した（スクリプト `scripts/march31_week_anomaly_et.py`、出力 `outputs/march31_week_anomaly_et_out.txt`、commit/pushなし）。定義：週は America/New_York 暦の月〜日週、エントリーは ET月曜最初のM1バー ask始値、決済は ET金曜セッション最終バー bid終値、RSIは ET 1H集計・単純平均版(14)・70以上で見送り／利確、対照群は同銘柄の対象週以外の全ET週、MCはシード42・20,000回（JST版と同一条件）。

- **ET月曜00:00のバーは存在する**：6,330組合せ中 6,051件で00:00 ETちょうどのバーがあり、USD_JPY では302週中299週。JST版の「月曜0:00は実行不能」とは違い、ETアンカーなら00:00エントリーは文字通り実行可能。ET月曜00:00は JST月曜13:00（EDT時）に当たる。
- **USD_JPY ベースライン（ET）**：年別 +0.99 / −0.45 / +1.67 / +0.04 / −1.32 / −0.14%、合計 +0.80%、平均 +0.133%、3勝3敗。対照群（ET、n=297）は平均 +0.097%・勝率57.9%で、MC p=0.4913。JST版（平均 +0.054%、p=0.5575）より数字は良くなったが、通常週と区別できない点は同じ。
- **全銘柄プール（ET）**：対象は n=114（126ではない。2021・2024・2026年の対象週の金曜がグッドフライデーに当たり、指数・商品の一部にセッションが無かったため）で平均 −0.238%、対照群 +0.044%。JST版（−0.249%）とほぼ同じで、やはりマイナス。
- **RSIフィルタ版（ET）**：利確発動は見送りを除く99件中97件（98%）で、JST版と同じく「ほぼ全トレードの決済を週前半に変える別戦略」化している。プール合計はベースライン −27.16% → RSI版 +6.63%（見送り0換算）に改善するが、主因は2025年の大負け週の早期降り（例 SPX500_USD 2025: −8.54% → +1.42%、NAS100_USD 2025: −8.82% → +0.92%）で、USD_JPY の RSI版平均も +0.270%（見送り0換算）と小さく、n=6では誤差の範囲。
- **最良銘柄も変わらず**：EUR_AUD が平均 +0.989%・MC p=0.0047で再び最良だが、Bonferroni 基準（0.0024）を通過せず、中央値は +0.117%で2025年の +5.15% 1件依存のまま。

よって「時刻アンカーを NY に変えればアノマリーが出る」という留保は、この1本の固定定義では潰れた。残るのは、元の MT5 画面が示す「持ち越し型の決済ルール」とは別物だという点（上記の画面解析どおり）で、強制決済版のアノマリー主張自体は JST・ET 両アンカーで反証されたままである。
