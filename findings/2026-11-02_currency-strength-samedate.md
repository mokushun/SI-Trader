# 検証サマリー 2026-11-02（通貨強弱×同日同時間マッチ）

検証者: Muse
根拠:
- `scripts/currency_strength_samedate.py`（引数 strict / tolerant で2定義）
- `outputs/currency_strength_samedate_strict.json` / `_tolerant.json` と各 .log

## 問い

ユーザーの追加仮説（2026-11-02）:
- 1時間足くらいで、過去5年の同日同時間に最強と最弱のペアが
  （今と）同じだったときのみ買う、という条件付けはどうか。

## 定義（固定）

- 強弱は前稿（currency-strength-firstpass）と同一: 5通貨10ペア、
  過去 L バーの mid 対数リターンの通貨別平均。1時間足、L∈{4,12,24}、
  保有 H∈{1,4,8}、エントリー次バー始値・決済 H 本目終値、スプレッド込み、
  スワップ・手数料なし。
- 「同日同時間」: JST 暦で同じ月日・同じ時刻、1〜5年前。
  過去年は、その時刻にバーが存在し強弱が計算できた場合のみ「利用可能」
  と数える（週末・祝日は利用不可であって不一致ではない）。
- 母集団: 2021-01-01〜2026-10-30 の意思決定バーで、過去5年のうち
  3年以上が利用可能なもの。
- バリアントA（本命）: 利用可能な過去年のうち、今と同じ順序付き
  （最強, 最弱）ペアだった年の数でバケット化（0 / 1 / 2 / 3+）し、
  今のペアを順張りで売買（逆張りも併記、結論は順張りで代表）。
  対照はバケット0（一致なし）。
- バリアントB（副）: 今日のペアとは無関係に、過去年の3年以上が
  互いに同じペアで一致していたら、その歴史的ペアを順張りで売買。
- 強弱の連続性条件は2定義で実施:
  - strict: ルックバック窓が完全に連続（前稿と同一）。
  - tolerant: 窓内の小さい欠け（合計8時間まで）は許容し、
    週末規模の跨ぎ（窓スパン > L+8 時間）だけ除外。事後の言い訳ではなく
    感度として両方を報告する。

## 結論

**バリアントAは成立しない。一致年数が増えるほど良くなる単調な関係は
どちらの定義にも無く、一致1年はむしろ無条件（一致0）より悪い。
一致の頻度自体がほぼ偶然の水準だった。**

### 頻度の問題（この仮説の構造的な弱さ）

- 順序付きペアは20通りなので、偶然の一致率は1年あたり5%。
  5年中2年以上の一致は偶然でも約2.3%、3年以上は約0.12%しか起きない。
  実測（strict, L=4）: 一致1年 17.2% / 2年 1.9% / 3年以上 0.12%（30件/6年）
  で、ほぼ偶然どおり。「3年以上一致したら買う」は年5回程度しか
  発火せず、その30件の成績も悪い（下記）。
- strict 定義では「過去5年すべて利用可能」なケース自体が評価期間に
  ゼロだった（最大4年）。暦の曜日が5年で6〜7スロット回るため、
  同日が週末に当たる年がほぼ必ず混ざる。

### バリアントAの成績（順張り、ネット平均%）

strict:
- L=4: 一致0 −0.0181/−0.0175/−0.0167（H=1/4/8）に対し、一致1
  −0.0215/−0.0252/−0.0272（全て悪化）。一致2（n=472/445/408）は
  グロス +0.0039/+0.0154/+0.0230、ネット −0.0169/−0.0059/+0.0015
  （t は −2.83/−0.49/+0.09）。一致3+（n≈30）は −0.0086/−0.0418/−0.0349。
- L=12: 一致2（n=140/123/98）グロス +0.0085/+0.0356/+0.0357、
  ネット −0.0194/+0.0088/+0.0070（t −2.04/+0.47/+0.24）。一致3+（n=7〜10）
  は全てマイナス。一致1は一致0とほぼ同じか悪化。
- L=24: strict では過去年側の連続性条件で母集団が35件に崩壊し検証不能。

tolerant（L=24 が検証可能になる）:
- L=24: 一致1は全 H で一致0より悪化。 **一致2は明確にマイナス**
  （グロス −0.0139/−0.0455/−0.1232、H=8 ネット −0.1448%、n=143）。
- L=4/L=12 の一致3+ は tolerant ではプラスに転じる箇所がある
  （例 L=12 H=8: ネット +0.1684%、n=21、t=1.67）が、strict では
  マイナスであり、定義を変えると符号が変わる n≈20〜40 のバケットは
  ノイズと読むのが妥当。

### バリアントB（過去年同士のコンセンサス）

- グロスは strict 6設定・tolerant 9設定すべてプラスで、ネットも
  多数プラス（最大 tolerant L=12 H=8: +0.0993%、n=111、t=2.24）。
- 期間分割（2021–23 / 2024–26）: 前後半ともネットがプラスなのは
  15設定中3設定で、すべて L=12（strict H=8: +0.0156/+0.0875、
  tolerant H=4: +0.0890/+0.0371、tolerant H=8: +0.1712/+0.0425）。
  それ以外は符号が入れ替わる（特に L=24 tolerant は
  H=4 −0.0541/+0.1099、H=8 −0.2070/+0.2334 と大きく反転）。
  L=12 に寄っている点は単なる最大値より少しだけ筋が良いが、
  n は 54〜129 で設定間のトレードも重なり、多重比較の中での
  t≈2.2 は証拠としては弱い。
- 訂正履歴: 本節は初版で期間分割の数値を取り違えて記載した
  （「+0.2314% vs −0.0068% で崩れる」は誤り）。上記が正しい値で、
  結論の強さは「期間で崩れる」から「L=12 に限れば前後半とも
  プラスだが n が小さく有意とは言えない」に弱めた。

## 解釈

同日同時間の「強弱の再現」は、起きる頻度が偶然の計算と一致し、
起きた後の値動きにも一貫した方向性が無い。暦の一致はフローの
再現を意味しない、というのがこの範囲での結論。
残る形があるとすればバリアントBの L=12 系だが、現状は
「前後半ともプラスだが n が小さく有意でない」小さな斑にすぎず、
やるなら定義固定のうえ前方記録で数年かけて判定するしかない
（発火は年20〜50回程度）。

## 限界・不確かな点

- L=24 strict の検証不能は定義（連続性）由来であり、「効果なし」とは
  別。tolerant で代替し、そちらでは一致条件はむしろ有害だった。
- t 値は保有窓の重なりを無視した素朴な値。結論は平均の大きさと
  定義・期間での符号の一貫性に置いている。
- 「同日」は JST 暦で固定した。NY 暦（ET）基準の同日は別定義として
  あり得るが、本検証の範囲外（定義を増やすなら事前宣言してから）。
