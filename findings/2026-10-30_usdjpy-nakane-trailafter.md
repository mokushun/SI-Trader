# 検証サマリー 2026-10-30（仲値後トレーリング：09:54 から開始する案）

検証者: Muse
根拠: `scripts/usdjpy_nakane_trailafter.py` / `outputs/usdjpy_nakane_trailafter_out.txt`

## 問い

ユーザーの案（2026-10-30）：09:55 固定決済の代わりに、09:54 からトレーリングストップを
始めれば、仲値を過ぎても上げ続ける日を取りに行けるのではないか。

## 定義

- m1.db、5ペア、ロングのみ、exit 日 火〜金、2020-10〜2026-10
- 00:00 ask 始値エントリー。木曜は両案とも 05:35 固定（スワップ回避）
- 非木曜の比較: base = 09:55 bid 始値決済 /
  trail = 09:54 時点でネイティブトレーリングを付けたものとして模す
  （初期最大は 09:54 の bid 始値、ストップ = bid 高値の最大 − 距離）
- 距離 10 / 20 pip、強制決済の上限 11:00 / 15:00、バー内順序は悲観 P / 楽観 O

## 結論

**これも固定 09:55 決済に勝てない。全ペア・全変種で平均と PF が下がる。**
（唯一の例外は AUD の距離20・上限15:00 だが、AUD 自体のエッジがほぼゼロで、
順序の仮定でも揺れるため採用根拠にならない。）

## 根拠（非木曜、n=942/ペア）

- USD: base +3.61 pip / PF 1.314 → trail は最良でも +2.67（距離10・上限15:00・P）、
  他は +1.93〜+2.55。ドラッグは約 −0.9〜−1.7 pip
- EUR: +2.82 / 1.226 → +1.01〜+1.72
- GBP: +3.40 / 1.214 → +0.87〜+1.86
- CHF: +2.97 / 1.257 → +0.61〜+1.30
- AUD: +0.75 / 1.067 → 大半が 0 前後かマイナス
- 仕組み: 09:55 以降の平均経路は下落（mid で 09:55 +3.1 → 10:30 +1.6）。
  仲値の山を過ぎたあとは「10pip の押しに当たらず上げ続ける日」より
  「先に 10pip 押す日」が多く、ほぼ全トレードで 10pip の譲歩を払って
  たまの延長を取りに行く形になり、割に合わない
- バー内順序 P/O の差は最大 0.9 pip 程度あるが、結論は両仮定で不変

## 位置づけ

- 保有中トレーリング (60, 10) も、仲値後トレーリングも、どちらも固定時刻決済に劣る。
  このトレードのエッジは「仲値フローの時間構造」そのもので、価格追従型の
  出口はその形と噛み合わない、という一貫した結果
