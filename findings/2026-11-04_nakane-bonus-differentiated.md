# 仲値ゴトー日ボーナスは一律でよいか（2026-11-04、Muse）

スクリプト: `scripts/nakane_bonus_differentiated.py`
出力: `outputs/nakane_bonus_differentiated_out.txt`
前提: 素の表は HAND2。全変種ともゴトー日あたりの平均ボーナス合計を
15,000（=5ペア×3,000）に揃えたので、出来高・平均露出は不変。

## 前提の確認: ゴトー日の伸びは一律ではない

スコア（FULL と POST のゴトー平均の平均）は −0.71（AUD 金）〜 +12.92（USD 木）。
頑健なのは曜日効果で、**木曜ゴトーは全ペア・両時代で最大**（スコア +8.6〜+12.9）。
ペアでは GBP/EUR が安定して強く、AUD が弱い（火 +1.37、金 −0.71 は POST の
−3.96 が効いたもの。全期間で唯一のマイナス圏セル）。

## 変種の成績（円、×1.4 込み）

- B0 一律3000: FULL +1,245,850（t 4.74）、POST t 5.13
- B-pair（ペア別: USD 3100 / GBP 3600 / AUD 1700 / EUR 3500 / CHF 3200）:
  全時代で小幅に改善（FULL +1,283,247・t 4.81、POST t 5.22、最悪月ほぼ不変、
  露出も不変 37,240）。1バケットあたりの n が4倍あり、最も信じられる改善
- B-wd（曜日別: 火2500/水2700/木4500/金2200）: PRE は改善するが POST の
  t は 5.01 に低下、最悪日 −38,041、木曜ゴトー露出 41,580 に集中
- B-cell（セル別比例、AUD 金は 0）: 紙の上では最良（FULL +1,380,083・t 4.95）
  だが、n≈60〜120/セルの平均で20セルを作り同じデータで評価した
  インサンプル最適化であり、最悪日は −39,127 に悪化。割り引いて見るべき

## 結論

- 変えるなら B-pair 程度の緩いペア別傾斜までが妥当。セル単位の比例は
  ノイズ追跡の色が濃い
- セル単位で唯一はっきりしている例外は AUD 金曜ゴトー（POST 唯一の
  マイナスセルに現行は 4,340 単位が乗る）
- 効果の大きさは素の表の選択に比べれば二階の話で、一律3000 のままでも
  測定上の不利益は小さい。採用はユーザーの判断
