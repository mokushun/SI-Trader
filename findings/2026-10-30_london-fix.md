## 問い

WM/Reuters ロンドンフィックス（16:00 ロンドン時間）前後に、
仲値（09:55 JST）のような一方向で取れる歪み、あるいは条件付きで取れる歪みはあるか。

## 定義（固定仕様）

- データ: m1.db、2020-10〜2026-10（EUR/USD のみ 2020-01〜）、月〜金、n≈1,550〜1,770 日/ペア
- T = 16:00 Europe/London（夏時間込みで tz 変換。JST では夏 翌0:00 / 冬 翌1:00）
- 約定は指定時刻の足の始値（仲値検証と同方式）。mid = (bid+ask)/2 の始値
- 対象: GBP/USD, EUR/USD, USD/JPY, EUR/GBP, GBP/JPY, AUD/USD, USD/CHF
- 価格のみ、スワップなし

## 結論

**仲値型の無条件の歪みは無い。歪み自体は2つ実在するが、どちらも往復スプレッドとほぼ同額で、
OANDA の実価格では手元に残らない。唯一の残候補は「月末日のフィックス直後の USD 高」で、
ただし n=72・近年に集中・多重検定割れの水準なので「確定」ではなく監視候補。**

## 根拠

### 1. 無条件ドリフト: ゼロ
- 事前 T-30→T の mid: GBP/USD −0.38 (t=−0.99)、EUR/USD −0.49 (t=−1.67)、
  USD/JPY +0.63 (t=+1.73)、EUR/GBP +0.03、GBP/JPY +0.32、AUD/USD +0.13、USD/CHF +0.13 pip。
  仲値ロング（USD/JPY +3.85 pip / t=3.39）のような一方向フローは見えない
- 事後 T→T+30 の mid も +0.04〜+0.79 pip でほぼゼロ。exec は全ペア・全窓でマイナス
  （スプレッド 1.3〜2.9 pip がそのまま乗る）
- 平均パス（T-60→T+60）も全ペア ±1 pip 以内で平坦
- ボラとスプレッドにも目立つ歪みなし: |1分変化| の20分合計は T 周辺が対照（14時台）比
  +2〜+13% 程度で、スプレッド中央値は T 周辺と対照時刻で同一（例 GBP/USD 1.76 vs 1.78）

### 2. 条件付きリバーサル（fade）は実在するが gross = スプレッド
- pre（T-30→T）と post（T→T+30）の相関は欧州系で −0.08〜−0.15
  （GBP/USD −0.095、EUR/USD −0.101、EUR/GBP −0.122、USD/CHF −0.076。USD/JPY だけ +0.10 と逆）
- T で pre の逆を張る fade の gross: EUR/USD +0.66 (t=2.87)、EUR/GBP +0.39 (t=2.83)、
  USD/CHF +0.61 (t=2.90) pip。大きな pre（上位25%）の日だけに絞ると gross +1.1〜+1.7 pip (t=2.2〜3.5)
- しかし正確な exec では fade 全体 −0.8〜−1.9 pip、**大きな pre の日でも
  GBP/USD −0.06 / EUR/USD −0.01 / EUR/GBP −0.12 / USD/CHF −0.35 pip とほぼ寸分ゼロ**。
  リバーサルの総量が往復スプレッド1回分と一致する＝フィックスの巻き戻しは
  価格には織り込まれていて、スプレッドを払う側には残らない

### 3. 直前5分 T-5→T の micro な上昇（参考・取引不能）
- mid で GBP/USD +0.46 (t=3.1)、USD/JPY +0.46 (t=3.0)、GBP/JPY +1.24 (t=5.5)、AUD/USD +0.50 (t=5.7) pip。
  多くは 2024+ に強い（EUR/USD は前半 +0.03 → 後半 +0.58）。ただし gross でも
  スプレッド（1.5〜2.9 pip）未満で、フィックス価格そのもので約定できる手段が無い限り取れない

### 4. 月末候補: フィックス直後 30分の USD 高
- 月末日（月内最終営業日、n=72）の T→T+30 は 5 USD ペア全部が USD 高方向:
  USD/JPY mid +3.62 (t=2.74)、GBP/USD を USD 買いに換算 +3.44 (t=2.35)、
  AUD/USD 換算 +2.35 (t=2.24)、USD/CHF +2.21、EUR/USD 換算 +2.11
- 5ペア合成（bp）: 月末 +2.74 bp (t=2.70, PF 2.30) vs 非月末 −0.26 bp。
  事前 T-30→T は月末 −1.51 bp (t=−0.75) と逆方向の弱い USD 安で、絵としては
  「月末リバランスの USD 売りがフィックスで出尽くし、直後に戻す」に合う
- exec（T で USD を買い T+30）: USD/JPY +2.10 (t=1.59)、GBP/USD +1.68 (t=1.15)、
  AUD/USD +1.06、USD/CHF +0.71、EUR/USD +0.64 pip — 方向は揃うが個別は有意でない

## 不確かな点（月末候補について）

- **期間依存が強い**: 合成の内訳は 2020-10〜2023 が +1.28 bp (t=0.83, n=39)、
  2024+ が +4.47 bp (t=3.67, n=33)。USD/JPY exec も前半 −0.87 → 後半 +5.61 pip。
  「最近だけ効いている」ものは消える候補の典型でもある
- 四半期末（n=24）に絞ると +0.96 bp (t=0.57) と強くならない — 「月末ほどフローが大きい」
  という素直な予想と合わない
- n=72 は月1回しか増えない。多重に切り口を見た後の t=2.7 は割引が必要
- 月末フローは本来、その月の株・債券の動きで方向が決まるもの（ヘッジ比率調整）で、
  無条件に毎月 USD 高という形は理論的には素朴すぎる。年の後半だけ方向が揃った
  可能性（相場レジームの偶然）を排除できない
- 実行は JST 0:00/1:00 の月1回。やるなら最小単位で USD/JPY 1ペアのみ、
  数ヶ月〜1年かけて前方検証する性質のもので、確立したエッジとして扱わない
