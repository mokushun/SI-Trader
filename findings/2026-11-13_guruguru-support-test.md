# グルトレ「サポート有無」検証（2026-11-13）

スクリプト: `scripts/guruguru_support_test.py` / 出力: `findings/2026-11-13_guruguru-support-test_out.txt`

## 問い

両建てグリッド（子本体）の逆行側含み損を、サポート（方向を持った10倍の錨ポジション）が
本当に打ち消すのか。サポート有/無だけを差し替え、全決済したときの純資産で比較した。

## 定義（固定）

- USD_JPY、m1.db（OANDAフィード、bid/ask）。JST暦月の月次ラン、完全月のみ n=141（2015-02〜2026-10）。
- 子本体: 10pip刻みの全レベルに買い/売り両スロット（各1,000通貨）、初回タッチで約定、
  利確+50pip、損切りなし、決済後は再約定可。バンドは開始mid ±3.00円（0.10絶対グリッド）。
- サポート: バンド内の1.00絶対ラインに触れるたび10,000通貨、ラン中は決済しない。
  LONG変種（買いサポート）/ SHORT変種 / OFF（子本体のみ）の3変種。子本体は3変種共通。
- 終了時に最終バーの bid/ask で全ポジションを時価評価（＝全決済時の純資産）。ラン中の最悪時価も記録。
- スワップなし、証拠金ゲートなし。M1内の順序は近似。

|---|---|---|---|
| ALL (n=141) | −17,757 / +4,736 / 57.4% | −3,287 / +20,905 / 70.2% | −33,878 |
| PRE (n=68) | −5,199 / +7,771 / 64.7% | −3,961 / +18,744 / 70.6% | −8,449 |
| POST (n=73) | −29,456 / +75 / 50.7% | −2,659 / +25,474 / 69.9% | −57,566 |

- 子本体のみ: 実現は月平均 +69,495（利確 平均138回/月）と大きく拾うが、終了時含みが
  平均 −87,252 で上回り、月末全決済では平均マイナス。中央値は小プラス＝「普段は小勝ち、
  トレンド月で吐き出す」形。POSTでは悪化（実現 +80,627 vs 含み −110,082）。
- ラン中最悪時価: 平均 OFF −75,774 / SUP-L −108,515、最深 OFF −436,168 / SUP-L −702,515。
  サポートは終了時点の成績を改善しても、途中の含み損は全変種で深くする。

## ワースト（SUP-L）

下落の巻き戻し月に集中: 2024-07（Δ−10.35円、キャリー巻き戻し）−639,767、
2016-02 −433,741、2022-11 −407,268、2016-06（Brexit）−391,918、2022-12（YCC修正）−375,660。
いずれもバンド±3円を突き抜ける月で、サポート3〜4本で −19万〜−36万の損失。
逆に 2016-11（Δ+8.52）は子本体 −419,056 をサポート +601,370 が救済して +182,314。

## 結論

1. **サポートは保険ではなく、方向へのレバレッジである。** 「含み損を打ち消す」は
   方向が当たった場合の記述でしかない。外した場合は打ち消すどころか損失と
   ラン中最悪時価の両方を拡大する（最深 −70万 vs OFF −44万、本構成比）。
2. 子本体単独は両建てリピートの既知の性質そのもの: レンジで拾い、トレンドで
   階段含み損を払う。月末全決済ベースでは平均マイナス、POSTでは悪化。
3. SUP-L の通算 ≈ 0・勝率70% は、標本期間の USD_JPY が 120→158 と一方向に
   上がったことの反映であり、構造的な優位ではない。SUP-L の実装は「ドル最強・
   円最弱」の既存キャリー（DCA＋クリックのドルロング）と同一リスク因子の二重化に
   なり、2024-07 型の月には全口座同時に効く。
4. 規模注意: 本構成（サポート最大7本×1万通貨＋子本体最大122本）は現在の
   OANDA口座（純資産約80万）ではラン中最悪時価 −70万に耐えられない。
   実装を検討するなら大幅な縮小が前提で、その場合も得るものは既存キャリーの複製。

## 限界

- 月末強制全決済は測定の物差しであり、実運用の「トレンド転換で全決済」という
  裁量は再現していない（裁量の巧拙は測れない）。
- サポートの上方ライン約定は逆指値扱い（手法に甘い前提）。指値のみなら SUP-L は
  上昇月にさらに弱く、下落月の損失もやや小さい。
- スワップ除外。買いサポートと子本体ショート在庫のスワップは月あたり1万円級の
  影響があり得るが、±40万〜100万の尾部の結論は変わらない。
- USD_JPY のみ。EUR/GBP は基本形の設計対象外（値幅・ボラが違う）で未検証。
