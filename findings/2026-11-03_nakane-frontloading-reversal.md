# 仲値: 買いの前倒しと仲値後の反転（2026-11-03、Muse）

スクリプト: `scripts/nakane_frontloading_reversal.py`
出力: `outputs/nakane_frontloading_reversal_out.txt`、
`outputs/nakane_gotobi_postfix_short_out.txt`（ゴトー日限定の仲値後ショート、インライン測定）
データ: 2015年版 m1.db、火・水・金決済日のみ。時代: E1 2015-17、E2 2018〜2020-09、
E3 2020-10〜2023、E4 2024〜2026-10。区間分解は mid、売買判定は実行可能価格。

ユーザーのイメージの検証: (a) 大昔は 9:30 頃から買われ、その後 9:00 買い→8:00 買いと
前倒しされた。(b) 仲値で不自然に上がった後は落ちていた。

## 結論

- **最後の25分（09:30→09:55）の買いは全時代でほぼ不変。** USD_JPY は
  E1 +1.11（t=2.42）、E2 +1.58（t=3.88）、E3 +1.70（t=3.32）、E4 +1.67（t=2.52）。
  ペア平均でも +0.98 → +1.21 → +1.33 → +1.51 とむしろ微増。
  フロントランニングが実需のフィキシング買いを食って消した形にはなっていない
- **前倒しは「早い時間帯が新たに強くなった」形で起きた。** 全日ベースでは
  09:00-09:30 が E1/E2 の −0.25/−0.31（ペア平均）から E3 +0.25 に転じ、
  窓全体の伸びは主に 00:00-08:00（+2.56/+0.08 → +3.38/+4.26）が担った
- **ゴトー日の USD_JPY では前倒しがはっきり見える**（n=82〜97/時代、参考値）:
  E1 は 09:30-09:55 が +2.92（t=3.04）で中心 → E2 で 08:00台 +2.68（t=2.28）が加わり →
  E3 は 00:00-08:00 が +6.37 と中心になり 09:30 台は −0.25 に消え → E4 は 08:00台
  +3.37（t=2.98）が中心。ユーザーの「9:30買い→9:00買い→8:00買い」という
  イメージに最も近いのはこのゴトー日の推移
- **仲値後の下落は実在する（mid）。** 09:55→10:30 のペア平均は
  E1 −1.11、E2 −1.14、E3 −1.29、E4 −0.71 と全時代マイナス。USD_JPY は
  E1 −1.17（t=−1.97）、E2 −1.02（t=−2.28）、E3 −1.83（t=−3.28）、E4 −0.30（n.s.）と
  直近で弱まった。12:00 までだと E1 が −3.66（USD −3.85、t=−2.93）と大きい
- **しかし無条件の仲値後ショートは実行可能価格で全時代・全ペアほぼ負け**
  （反転 1〜2pip ＜ 往復スプレッド）。ユーザーが半年実売買して駄目だったという
  報告（2026-10-28、曜日×ペア PF の大半が 1 未満）と整合する
- **例外の芽: ゴトー日限定・USD_JPY・10:30 決済のショート** は全期間
  +1.80pip（PF 1.570、t=2.95、n=355）で、時代別も E1 +1.66 / E2 −0.20 /
  E3 +1.87（t=1.96）/ E4 +3.78（PF 2.093、t=2.37）と大崩れしない。
  ただし多重比較の中の最良セルであり、ゴトー日×USD×10:30 という事後の切り口。
  「候補」止まりで、やるなら前方記録が先

## 2015年より前のデータについて

- OANDA の M1 は 2015 年開始（現 DB）。それ以前は別ソースが要る
- **Dukascopy の tick（bid/ask）が本命。** Tickstory の公開リストでは開始日は
  USD/JPY 2003-05-05、GBP/JPY・EUR/JPY・CHF/JPY 2003-08-04、AUD/JPY 2003-12-01 と、
  仲値5ペア全て 2003 年からある。tick から m1.db と同じ形式（bid/ask OHLC の M1）を
  構築でき、仲値検証に必要なのは東京午前（前日 15:00 UTC〜03:00 UTC）だけなので
  対象は全時間の半分程度で済む
- 注意: (1) Dukascopy は OANDA とは別フィードでスプレッドが違う（ECN で一般に狭い）。
  価格パターン（前倒し・反転・ゴトー日プレミアムの有無）の検証には使えるが、
  実行可能ネットは OANDA 前提と切り分けること。(2) この VM から datafeed を
  直接叩いたところ即 429（スロットル）になった。ダウンロードは低速ペーシング
  （dukascopy-node 等の既存ツール）前提で、デコード検証はまだ出来ていない
- 代替: HistData.com の M1（2000〜2002年開始、年次 zip で取得は容易）は
  bid のみでスプレッドが取れない。ユーザーの MT5 は 1時間足で 2003 年〜の
  履歴がある（2026-11-01 のテスター画面で確認）が、M1 の深さは未確認で、
  テスターのスプレッドは当時の実績ではない点に注意

## 不確かな点

- ゴトー日の時代別セルは n=82〜97 と小さく、前倒しの「推移」は示唆レベル
- 「9:00 までに完了した割合」のような比率指標は分母（窓全体）が小さい
  E2 で不安定になるため、本文は区間の絶対値で判断した
- 木曜を除く母集団（09:55 決済が無いため）。木曜の仲値後も価格は存在するが未測定
